# O1: Adventure online world (servers, host migration, social)

Reuse the arena's stack (docs/ONLINE.md, src/online.js, src/netsync.js): PeerJS 1.5.4 WebRTC, MQTT lobby on the public EMQX broker, wire conventions (plain objects, seq numbers, ctl reliable + fast unordered channels, bufferedAmount congestion skip).

- Topology: star. One player is the world host; every other player keeps one PeerJS connection to the host. Max 16 players per server.
- Discovery: retained MQTT message per server on `pokearena/adv1/servers/<serverId>` = `{ v, name, n, max: 16, host: peerId, succ: [peerIds], players: [names], t }`, refreshed every 10 s by the host, cleared on close (last-will on crash). Entries older than 30 s are ignored. Menu: Play Online (auto-join: the fullest server with n < max, else start a new one and host it), Server List (name, players, ping after connect), Join Friend (type a name, finds the server listing them), Offline (no network, same code path with a local fake host).
- Host owns: server clock (`epoch` so everyone computes the same game time; day/night and spawn tables use it), the player list with latest states, and wild groups. Wild spawning moves to the host: it runs the W1b spawner around EVERY player, simulates groups within 50 tiles of any player, and sends each guest only groups within 60 tiles of that guest (area of interest) at 8 Hz on fast: `{t:'w', q, g: [[id, species, x, y, face, anim], ...], gone: [ids]}`. Guests render remote wild mons interpolated 150 ms behind. Offline, the local fake host does the same in-process.
- Each player owns: their trainer + follower movement (10 Hz on fast `{t:'p', q, x, y, z, face, mv, f: [fx, fy, fz, fface, fmv], room?}`; the host relays to everyone within 60 tiles; nobody else simulates them), their save, story state and battles. Players in rooms only see others in the same room.
- Fights: touching a wild group sends `{t:'claim', g}`; host grants (removes the group from everyone else's world) or denies (already claimed). The fight runs locally on the claimer's machine exactly as offline. While fighting, the claimer sends a light battle view at 8 Hz `{t:'bv', mons: [[species, x, y, z, face, anim, hpFrac]]}` that the host relays within 60 tiles, so others SEE the fight (no damage sim on their side). On end `{t:'bend', g, result}`.
- Trainer NPCs and story are per player and never synced (phased world).
- Player menu: walk up to a player, A/E opens Challenge / Trade / Profile.
- PvP: accepting opens a DIRECT PeerJS connection between the two (not via the host) and runs a normal online battle with the existing arena netcode, the arena being the W1a world box around them. Others see it through bv relays from the fight host. No EXP, no money, no fainting consequences.
- Trading: over a direct connection; both pick a mon, both confirm twice; each removes its mon and adds the other's (original trainer kept), then both auto-save prompt.
- Chat: Enter opens a text field (max 80 chars); `{t:'chat', s}` to the host, broadcast to the server; speech bubble over the player for 5 s plus a chat log (last 8 lines, fades). A small word filter masks slurs with *.
- Host migration: the host broadcasts `succ` (peer ids in join order) every 5 s. If the host's connection drops (or 6 s without any host message), every guest promotes the first live entry of `succ`: that player starts hosting (re-registers the MQTT entry with the same serverId), the others connect to it. Wild groups respawn fresh; players resend their states; fights in progress continue locally and report their end to the new host.
- Co-op joining someone's wild fight needs battles with more than 2 sides: O2, not now. In O1 pressing A near someone's fight shows "Co-op joining comes later".
- Tests: tools/adv-net-check.mjs runs 16 headless clients over an in-memory transport with latency and loss: everyone sees nearby players, area of interest culls far ones, two claims on one group grant exactly one, a host drop migrates to the successor within 7 s with all 15 others reconnected, chat reaches everyone, per-guest download under 6 KB/s and host upload under 90 KB/s at 16 players.
